# Power BI Sales & Customer Analytics

## Project Overview

This project analyzes real-world transactional data from a local thread business in Surat using Power BI.

The objective of the project is to transform raw transactional data into meaningful business insights and understand both sales performance and customer behavior.

The analysis covers approximately 175,000 transaction records from April 2022 to March 2024, including 586 unique customers and around 54,000 bills.

The project is divided into four dashboards:

- Sales Analysis
- RFM Analysis
- Customer Lifetime Value (CLV) Analysis
- Customer Churn Analysis

## Tools Used

- Microsoft Excel
- Power BI
- Power Query
- DAX
- Data Cleaning
- Data Visualization

## Dashboard 1: Sales Analysis

The Sales Dashboard provides an overview of overall business performance.

Key metrics include:

- Total Sales: ₹325.05M
- Total Quantity: ~2M
- Total Orders: ~54K
- Total Customers: 586
- Average Order Value: ₹6.05K

The dashboard also analyzes sales trends, top-performing products, product categories, and top customers.

## Dashboard 2: RFM Analysis

RFM Analysis was used to understand customer purchasing behavior based on:

- Recency – How recently a customer purchased
- Frequency – How frequently a customer purchased
- Monetary Value – How much the customer spent

Customers were segmented into:

- Champions
- Loyal Customers
- Potential Loyal
- At Risk
- Lost Customers

This analysis helps identify valuable customers and customers who may require re-engagement.

## Dashboard 3: CLV Analysis

Customer Lifetime Value (CLV) Analysis was used to understand the financial value contributed by customers based on the available historical transaction data.

The dashboard identifies high-value customers, analyzes CLV distribution, and compares customer value across different customer segments.

## Dashboard 4: Churn Analysis

Churn Analysis identifies customers based on their inactivity period.

Customers were classified as:

- Active: Up to 90 days inactive
- At Risk: 91–180 days inactive
- Churned: More than 180 days inactive

This analysis helps identify customers who may require retention and re-engagement efforts.

## Key Business Insights

The analysis helps the business:

- Monitor overall sales performance
- Identify top-performing products and customers
- Understand customer purchasing behavior
- Identify financially valuable customers
- Detect customers at risk of churn
- Support customer retention and re-engagement decisions

## Project Conclusion

This project demonstrates how Power BI can be used to transform raw transactional data into actionable sales and customer insights.

By combining Sales, RFM, CLV, and Churn Analysis, the project provides a comprehensive view of both business performance and customer behavior.
